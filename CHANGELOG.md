# Changelog

All notable changes to this plugin are documented here.

## 0.5.0 - 2026-10-07

- Initial native thin Financial Ledger provider with ten deterministic action paths for Charges, factual corrections, approved immutable ChargeAdjustments, opening positions, balanced journals, Allocations/compensations and scoped reads.
- Require exact current Finance grants, source evidence, policy/approval binding, monetary scope, revision/fence and atomic persistence; physical organization/storage/source adapters remain unqualified.
